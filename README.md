## ⚙️ Configuration Philosophy

Nothing in this hub is hard-coded to a single workflow. A layered configuration model lets you shape behavior at three levels:

1. **Global defaults** — the baseline applied to every module.
2. **Per-game profiles** — overrides for a specific Roblox experience.
3. **Session toggles** — on-the-fly adjustments without saving.

Configurations are stored in plain, human-readable files so that you can back them up, share them, or sync them across machines with simple file copying. No proprietary format, no lock-in.
